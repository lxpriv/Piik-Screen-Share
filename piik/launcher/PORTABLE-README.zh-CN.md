# Piik 屏幕共享 · 朋友便携版

适用 Windows 10/11 64 位。免费、本地运行，已包含 Node.js、Piik 服务和公网隧道，无需安装开发工具。浏览器优先使用已安装的 Chrome，没有时使用 Edge。

1. 完整解压 ZIP 到任意可写文件夹，路径可以包含中文和空格；不要直接在压缩包中运行。
2. 双击 `piik\Piik-Screen-Share.exe`，点击“开始”。**KOOK 用户 ID 可选**：填写后消息显示你的服务器昵称；留空则不显示分享者这一行。程序会记住上次填写的 ID，也会记住清空状态，下次在同一解压目录运行时自动回填。填写时，KOOK 用户设置 → 高级设置 → 开启开发者模式，再右键自己的头像复制用户 ID。这不是机器人 ID 或 Bot Token。
3. 在自动打开的专用浏览器中开始分享并选择画面；出现有效预览后，机器人将邀请发送到“配置的 KOOK 文字频道”。
4. 点击窗口“停止”结束共享并移除自己这次的消息链接；关闭窗口也会完成清理。最小化保持共享。

需要桌面图标时，给 EXE 创建桌面**快捷方式**，不要把 EXE 单独复制出去。`piik` 与 `kook-bot` 两个文件夹必须保持并列；运行中不要移动或重命名整个目录。

每台电脑独立创建房间、邀请和消息记录。初次使用默认私密、无密码，完整邀请可免密加入，最多 10 位观众。开播期间电脑与浏览器需要保持运行。公网地址每次重建隧道时变化。

此包已配置同一个 KOOK 机器人，包含可读取的 Bot Token，只私下交给信任的朋友，不要公开上传。它不含原电脑的浏览器资料、房主身份、旧房间、历史消息或日志。首次使用无需填写 Token，也不必打开 KOOK 客户端。

多个朋友可以同时开播；各自的停止操作只更新本机记录的消息。不要互相复制运行后生成的 `data` 文件夹。填写 ID 时，机器人显示分享者在目标服务器的服务器昵称，每次开播和结束时重新查询；昵称变化无需重新配置，无服务器昵称时使用账号名称。留空时开始和结束消息都不显示 ID、昵称或空的“屏享主人”标签。运行中该选项不可更改，需先停止。

ID 偏好保存在 `piik/data/kook-user-id.txt`。保留原解压目录和 `data` 即可继续记住；清空后关闭窗口也会保存，不必先开播。

通过启动器打开的专用 Chrome/Edge，在选屏弹窗中默认勾选声音，仍需手动选择画面并确认，也可以取消音频勾选。共享整个屏幕时是系统声音；共享窗口/标签页时按浏览器提供的音频范围采集，不会自动开启麦克风。更新旧版本后，先关闭旧的专用共享浏览器窗口再启动，让新的浏览器启动参数生效。

消息文案仍可编辑 `kook-bot\messages.json`：`{owner}` 自动替换为当前服务器昵称，`{invite}` 替换为完整邀请。建议把 `{owner}` 单独放一行，留空 ID 时这一行自动省略。昵称按发消息时取值，不会持续轮询或反复重写历史通知。

提前关闭共享页面或整个专用浏览器后，仍可正常停止或退出。若只是 KOOK 消息更新失败，本地共享会关闭，窗口显示“频道消息更新待重试”；可以正常退出，原消息记录保留，下次启动后重试移除链接。本地清理仍未完成时，按提示重试“停止”。升级时先结束旧程序，再将新包覆盖到原解压目录，保留 `piik/data` 和 `kook-bot/data`；不要复制其他人的运行数据。自定义过的 `kook-bot/messages.json` 也请保留。

运行日志位于 `piik\logs\launcher.log`，机器人日志位于 `kook-bot\data\watch.err.log`。链接带跳转监控参数的兼容补丁已包含在服务端，无需手工删参数。

本包不需要 VPN 或付费服务器；实际异地观看仍取决于双方的网络通路。当前采用 WebRTC 直连，不包含媒体中转。

本机服务端口统一读取 `piik/server/.env` 中的 `PORT`，新包默认 `17887`。若提示端口被 Windows 保留或占用，先停止应用，再把 `PORT` 改为可用端口，无需分别修改浏览器、隧道或机器人脚本。
